# 東京・河口湖 2026/11/26–11/30

兩人的靜態行程頁。全站繁體中文，樣式在 `styles.css`，首頁是儲存庫根目錄的 `index.html`，給 GitHub Pages 直接託管。

## 啟用 GitHub Pages

1. 確認 `index.html` 已在 `main` 分支的儲存庫根目錄。
2. 打開此儲存庫的 **Settings > Pages**。
3. Source 選 **Deploy from a branch**。
4. Branch 選 **main**，資料夾選 **/ (root)**，再按 Save。
5. 幾分鐘後，網站會出現在 `https://<使用者或組織>.github.io/<儲存庫名稱>/`。

本機預覽：用瀏覽器直接開啟 `index.html` 即可。
